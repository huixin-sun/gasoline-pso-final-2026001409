# 数据与实现设置

本项目围绕汽油操作参数的离线优化，评估计算实现、性能和模型适用范围。方法及变量配置的参考资料列于报告和 README 末尾。

| 项目 | 本项目设置 |
|---|---|
| 输入与目标 | 预先固定27项输入，包含4项原料性质与23项操作量；RON和硫含量为两个目标 |
| 变量匹配 | 按仪表位号匹配工作簿与变量字典，避免中文同名项和列偏移 |
| 范围 | FT_1001.PV 为40–145；FT_9401.PV 为25–900，以附件四为准 |
| 同名位号 | EH-103采用TXE_3201A.DACA，范围300–550；不合并两个测点 |
| 预测器 | 两个独立27-50-1 ReLU网络，输入顺序一致，分别训练 |
| PSO参数 | c1=c2=0.5，w=0.8，归一化速度上限0.2 |
| 评价预算 | 应用128粒子120轮；质量实验96粒子80轮；计时20轮，各自公开配置 |
| 可行性 | 数值闭区间，容差1e-10；不可行值1e6加违反量，并约束RON非负 |
| 搜索框 | 主框为物理范围与训练边际范围交集，另做完整物理框敏感性 |
| 数据划分 | 时间先后260/65，训练内再划52条验证；给出完整样本编号 |
| 计算验证 | NumPy同步PSO的逐粒子与批量实现对照，已知函数、多种子及等预算比较 |

变量单位照录附件，其中可疑单位不自行改写。变量名与量程并不能证明各项可独立操控，真实设备联动约束需要工艺信息另行确认。本项目不生成或验证在线操作建议。

所有结论均由本项目的模型、数据划分、运行预算与实验记录支持。预测收益不等同于实测收益，判断正确性与适用性依据包括独立测试、解析函数性质、实现等价性和公平的计算实验。
